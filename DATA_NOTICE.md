# Dataset provenance

Street network derived from OpenStreetMap: copyright OpenStreetMap contributors.
https://www.openstreetmap.org/copyright
OpenStreetMap database licensing information: https://opendatacommons.org/licenses/odbl/

Network: Berlin scenario used in this study, retaining its largest connected component.
Traffic and EV routes are synthetic scenarios generated for this research using SUMO 1.24.0.
Three demand settings: 2650, 2800, 2950 veh/h; 100 background scenarios per demand.
Each background has p01 and p02 EV variants; goals use the selected three junctions.
The 70/15/15 partition is preserved in new_env/scenario_manifest.csv.
Simulation data are retained byte-for-byte from the source dataset.
No new software license has been assigned by this packaging operation.
